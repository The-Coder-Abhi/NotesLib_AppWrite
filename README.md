## 🚀 Features
* **Structured Organization:** Tailored for students to keep academic notes categorized and easily retrievable.
* **Robust Document Storage:** Fast and reliable file uploading and downloading capabilities.
* **Access Control:** Secure authentication and strict privacy rules ensuring users only access their own authorized documents and data.
* **Modern UI:** Built entirely with a declarative UI approach for a fluid and responsive native experience.

## 🛠️ Tech Stack
* **Frontend:** Android, Kotlin, Jetpack Compose
* **Backend:** Appwrite (Authentication, Databases, Storage)

## 🏗️ Technical Highlights & Migration
This project demonstrates backend flexibility and data migration skills. Originally architected with Firebase, the backend was successfully migrated to Appwrite to leverage its self-hosted capabilities and optimize the document storage and access control flow. 

## 💻 Getting Started

Follow these steps to run the project locally.

**Prerequisites:**
* Android Studio (Latest Version)
* An active Appwrite instance (Cloud or Self-Hosted)

**Installation:**
1. Clone the repository:
   `git clone https://github.com/The-Coder-Abhi/NotesLib_AppWrite.git`
2. Open the project in Android Studio.
3. Configure your Appwrite credentials:
   * Create a new project in your Appwrite console.
   * Add your `Endpoint` and `Project ID` to the relevant configuration file (e.g., `constants.kt` or `local.properties`).
4. Sync the Gradle files and build the project.
5. Run the application on an emulator or physical device.
